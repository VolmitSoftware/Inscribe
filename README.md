# Inscribe

Transfer selected enchantments from equipment into a book, then apply enchanted books through inventory clicks.

Requires Java 25 and Minecraft 26.1 through 26.3. Supports Spigot, Paper, and Folia. Vault is optional for money payments.

Build with `./gradlew.bat build buildSwiftSwamp`. The verified JAR is staged in `../BUILDS/Inscribe.jar`.

See the [documentation](../docs/inscribe.md) and [release repository](https://github.com/VolmitSoftware/Inscribe). Language downloads require a published catalog revision; see [language setup](../docs/inscribe/05-languages-editors.md).
